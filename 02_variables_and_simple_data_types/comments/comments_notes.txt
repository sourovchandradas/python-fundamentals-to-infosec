OVERVIEW
------------------------------------------------------------------------------------------------------------------------------------------------------------
Comments are an extremely useful feature in most programming languages. Everything you've written in your 
programs so far is Python code. As your programs become longer and more complicated, you should add notes within 
your programs that describe your overall approach to the problem you're solving. A comment allows you to write 
notes in English within your programs.


1. HOW DO YOU WRITE COMMENTS?
------------------------------------------------------------------------------------------------------------------------------------------------------------
* Definition: In Python, the hash mark (#) indicates a comment.
* Interpreter Behavior: Anything following a hash mark in your code is ignored by the Python interpreter.

Code Example:
>>> # Say hello to everyone.
>>> print("Hello Python people!")
Hello Python people!

* Explanation: Python ignores the first line and executes the second line.


2. WHAT KIND OF COMMENTS SHOULD YOU WRITE?
------------------------------------------------------------------------------------------------------------------------------------------------------------
* Primary Purpose: The main reason to write comments is to explain what your code is supposed to do and how you 
  are making it work. 
* Time Saver: When you return to a project after some time away, writing good comments can save you time by 
  summarizing your overall approach in clear English.
* Professional Standard: If you want to become a professional programmer or collaborate with other programmers, 
  you should write meaningful comments. Skilled programmers expect to see comments in code.
* Decision Rule: When determining whether to write a comment, ask yourself if you had to consider several 
  approaches before coming up with a reasonable way to make something work; if so, write a comment about 
  your solution.


3. TRY IT YOURSELF EXERCISES
------------------------------------------------------------------------------------------------------------------------------------------------------------
File naming standard: Use descriptive, lowercase snake_case names (e.g., adding_comments.py).
