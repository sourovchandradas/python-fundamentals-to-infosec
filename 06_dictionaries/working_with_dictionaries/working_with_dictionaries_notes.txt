=====================================================================================================================================================
                                                             WORKING WITH DICTIONARIES
=====================================================================================================================================================

OVERVIEW
-----------------------------------------------------------------------------------------------------------------------------------------------------
A dictionary in Python is a collection of key-value pairs. Each key is connected to a value, and you can use a key to access 
the value associated with that key. A key’s value can be a number, a string, a list, or even another dictionary. In fact, 
you can use any object that you can create in Python as a value in a dictionary. Dictionaries are wrapped in braces, {}, 
with a series of key-value pairs inside.


1. ACCESSING VALUES IN A DICTIONARY
-----------------------------------------------------------------------------------------------------------------------------------------------------
* Definition: A key-value pair is a set of values associated with each other. Every key is connected to its value by a colon, 
  and individual key-value pairs are separated by commas.
* Accessing Data: To get the value associated with a key, give the name of the dictionary and place the key inside square brackets.

Code Example:
alien_0 = {'color': 'green', 'points': 5}
print(alien_0['color'])

Output:
green

Code Example (Using Values):
alien_0 = {'color': 'green', 'points': 5}
new_points = alien_0['points']
print("You just earned " + str(new_points) + " points!")

Output:
You just earned 5 points!


2. ADDING NEW KEY-VALUE PAIRS & STARTING EMPTY
-----------------------------------------------------------------------------------------------------------------------------------------------------
* Dynamic Structure: Dictionaries are dynamic, and you can add new key-value pairs at any time by giving the dictionary name 
  followed by the new key in square brackets and setting it equal to the new value.
* Unordered Collections: Python does not care about the order in which key-value pairs are stored; it only tracks the connection 
  between each key and its value.

Code Example (Adding Pairs):
alien_0 = {'color': 'green', 'points': 5}
alien_0['x_position'] = 0
alien_0['y_position'] = 25
print(alien_0)

Output:
{'color': 'green', 'points': 5, 'y_position': 25, 'x_position': 0}

* Starting Empty: You can define an empty dictionary using empty braces {} and populate it line-by-line. This is useful when 
  storing user-supplied data or generating data automatically.

Code Example (Empty Dictionary):
alien_0 = {}
alien_0['color'] = 'green'
alien_0['points'] = 5
print(alien_0)

Output:
{'color': 'green', 'points': 5}


3. MODIFYING AND REMOVING VALUES IN A DICTIONARY
-----------------------------------------------------------------------------------------------------------------------------------------------------
* Modifying Values: To change a value, specify the dictionary name with the key in square brackets and assign a new value.

Code Example (Modifying Values):
alien_0 = {'x_position': 0, 'y_position': 25, 'speed': 'medium'}

if alien_0['speed'] == 'slow':
    x_increment = 1
elif alien_0['speed'] == 'medium':
    x_increment = 2
else:
    x_increment = 3

alien_0['x_position'] = alien_0['x_position'] + x_increment
print("New x-position: " + str(alien_0['x_position']))

Output:
New x-position: 2

* Removing Key-Value Pairs: Use the `del` statement with the dictionary name and the key you want to remove.
* Important Note: Deleted key-value pairs are removed permanently.

Code Example (Deleting Pairs):
alien_0 = {'color': 'green', 'points': 5}
del alien_0['points']
print(alien_0)

Output:
{'color': 'green'}


4. A DICTIONARY OF SIMILAR OBJECTS
-----------------------------------------------------------------------------------------------------------------------------------------------------
* Multiline Formatting: You can use a dictionary to store one kind of information about many objects. Break larger dictionaries 
  across multiple lines by indenting key-value pairs four spaces.
* Formatting Tip: It is good practice to include a trailing comma after the last key-value pair.

Code Example:
favorite_languages = {
    'jen': 'python',
    'sarah': 'c',
    'edward': 'ruby',
    'phil': 'python',
    }

print("Sarah's favorite language is " +
    favorite_languages['sarah'].title() +
    ".")

Output:
Sarah's favorite language is C.
