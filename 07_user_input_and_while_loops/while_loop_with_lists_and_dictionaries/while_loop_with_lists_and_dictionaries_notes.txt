=====================================================================================================================================================
                                                   WHILE LOOP WITH LISTS AND DICTIONARIES
=====================================================================================================================================================

OVERVIEW
-----------------------------------------------------------------------------------------------------------------------------------------------------
Up to this point, programs processed single pieces of user input independently. To handle complex application workflows, programs must store and 
organize multiple data points using lists and dictionaries. Crucial Technical Rule: You should NEVER modify a list (add or remove items) while
iterating over it with a for loop. Because a for loop keeps track of items using sequence indices, modifying the list during iteration causes
Python to miscalculate index positions, leading to skipped items or unexpected runtime behavior.
To safely alter, transfer, or clear items from a list as you process them, always use a while loop. Combining while loops with data structures
enables dynamic data collection, state modification, and flexible record storage.


1. MOVING ITEMS FROM ONE LIST TO ANOTHER
-----------------------------------------------------------------------------------------------------------------------------------------------------
* Practical Need: Web applications frequently process queue systems—such as moving newly registered users from an "unverified" queue to a 
  "confirmed" database, or processing pending shopping cart items into completed orders.

* Truthy / Falsy List Evaluation: In Python, a list used directly inside a conditional test evaluates to True if it contains at least one item, 
  and False when it is completely empty (`[]`). Therefore, `while unconfirmed_users:` will execute as long as elements remain in the list.

* LIFO Behavior with pop(): The `.pop()` method without arguments removes and returns the LAST item from a list (Last-In, First-Out order). 
  This continuously shrinks the source list until the loop condition becomes False.

Code Example (confirmed_users.py):
# Start with users that need to be verified, and an empty list to hold confirmed users.
>>> unconfirmed_users = ['alice', 'brian', 'candace']
>>> confirmed_users = []

# Verify each user until there are no more unconfirmed users.
# Move each verified user into the list of confirmed users.
>>> while unconfirmed_users:
>>>    current_user = unconfirmed_users.pop()
    
>>>    print("Verifying user: " + current_user.title())
>>>    confirmed_users.append(current_user)

# Display all confirmed users.
>>> print("\nThe following users have been confirmed:")
>>> for confirmed_user in confirmed_users:
>>>    print(confirmed_user.title())

Detailed Execution Trace:
1. Initial State: unconfirmed_users = ['alice', 'brian', 'candace'], confirmed_users = []
2. Iteration 1: .pop() removes 'candace'. current_user = 'candace'. Appended to confirmed_users.
3. Iteration 2: .pop() removes 'brian'. current_user = 'brian'. Appended to confirmed_users.
4. Iteration 3: .pop() removes 'alice'. current_user = 'alice'. Appended to confirmed_users.
5. Iteration 4: unconfirmed_users is now [] (empty / False). The while loop terminates naturally.

Output:
Verifying user: Candace
Verifying user: Brian
Verifying user: Alice

The following users have been confirmed:
Candace
Brian
Alice


2. REMOVING ALL INSTANCES OF SPECIFIC VALUES FROM A LIST
-----------------------------------------------------------------------------------------------------------------------------------------------------
* Limitation of remove(): The standard `list.remove('value')` method deletes ONLY the first matching occurrence of a value from a list. 
  If duplicate items exist across the list, calling `.remove()` once leaves the rest intact.

* Solution Strategy: Combine a while loop with the `in` membership operator (`while 'value' in list:`). The loop evaluates whether the duplicate 
  item still exists anywhere in the list. Inside the loop, `.remove()` deletes the first instance found, repeating this cycle until zero instances remain.

Code Example (pets.py):
>>> pets = ['dog', 'cat', 'dog', 'goldfish', 'cat', 'rabbit', 'cat']
>>> print("Original list:")
>>> print(pets)

# Remove all occurrences of 'cat' from the list
>>> while 'cat' in pets:
>>>     pets.remove('cat')

>>> print("\nUpdated list:")
>>> print(pets)

Output:
Original list:
['dog', 'cat', 'dog', 'goldfish', 'cat', 'rabbit', 'cat']

Updated list:
['dog', 'dog', 'goldfish', 'rabbit']

* Under the Hood: On each pass, Python scans `pets` from left to right. Once 'cat' is deleted, the list shrinks, indices adjust, and the while loop re-evaluates `while 'cat' in pets:` until all instances are completely purged.


3. FILLING A DICTIONARY WITH USER INPUT
-----------------------------------------------------------------------------------------------------------------------------------------------------
* Concept: A while loop can gather multi-variable user inputs per iteration and map them directly into a dictionary as key-value pairs
  (`dict[key] = value`).

* Application: Ideal for interactive surveys, polling apps, or continuous user registration systems where user responses need to be associated 
  with specific identifiers (e.g., matching a person's name to their poll response).

Code Example (mountain_poll.py):
>>> responses = {}

>>> # Set a flag to indicate that polling is active.
>>> polling_active = True

>>> while polling_active:
>>>     # Prompt for the person's name and response.
>>>     name = input("\nWhat is your name? ")
>>>     response = input("Which mountain would you like to climb someday? ")
    
>>>     # Store the response in the dictionary:
>>>     responses[name] = response
    
>>>     # Find out if anyone else is going to take the poll.
>>>     repeat = input("Would you like to let another person respond? (yes/ no) ")
>>>     if repeat.lower() == 'no':
>>>         polling_active = False

>>> # Polling is complete. Show the results.
>>> print("\n--- Poll Results ---")
>>> for name, response in responses.items():
>>>     print(name.title() + " would like to climb " + response.title() + ".")

Output:
What is your name? Eric
Which mountain would you like to climb someday? Denali
Would you like to let another person respond? (yes/ no) yes

What is your name? Lynn
Which mountain would you like to climb someday? Devil's Thumb
Would you like to let another person respond? (yes/ no) no

--- Poll Results ---
Lynn would like to climb Devil's Thumb.
Eric would like to climb Denali.
