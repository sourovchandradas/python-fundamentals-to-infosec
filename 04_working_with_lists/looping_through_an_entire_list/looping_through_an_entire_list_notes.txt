=====================================================================================================================================================
                                                      LOOPING THROUGH AN ENTIRE LIST
=====================================================================================================================================================

OVERVIEW
-----------------------------------------------------------------------------------------------------------------------------------------------------
You’ll often want to run through all entries in a list, performing the same task with each item. For example, in a game you might want to move 
every element on the screen by the same amount, or in a list of numbers you might want to perform the same statistical operation on every element. When you want to do the same action with every item in a list, you can use Python’s for loop to manage these tasks internally without repetitive code.


1. BASIC FOR LOOP SYNTAX
-----------------------------------------------------------------------------------------------------------------------------------------------------
* Definition: A for loop pulls each value from a list sequentially and stores it in a temporary variable to perform actions on it.

Code Example:
>>> developers = ['alice', 'bob', 'charlie', 'david']
>>> for developer in developers:
>>>     print(developer)
Output:
alice
bob
charlie
david

* Explanation: "For every developer in the list of developers, print the developer's name." Python repeats the loop once for each item in the list.


2. A CLOSER LOOK AT LOOPING AND NAMING CONVENTIONS
-----------------------------------------------------------------------------------------------------------------------------------------------------
* Execution Flow: Python reads the start line (`for developer in developers:`), retrieves 'alice', stores it in `developer`, and executes the indented 
  line (`print(developer)`). It repeats this sequence for 'bob', 'charlie' and 'david' until no items remain in the list.

* Temporary Variable Naming: Choose meaningful, singular variable names that represent a single item from a plural list to make code readable.

Code Example:
for cat in cats:
    print(cat)

for dog in dogs:
    print(dog)

for item in list_of_items:
    print(item)


3. DOING MORE WORK WITHIN A FOR LOOP
-----------------------------------------------------------------------------------------------------------------------------------------------------
* Multiple Indented Lines: Every indented line following the for statement is inside the loop and executes once for each item in the list.

Code Example:
>>> developers = ['alice', 'bob', 'charlie', 'david']
>>> for developer in developers:
>>>     print(f"Hello, {developer.title()}! Welcome to the team.")
>>>     print(f"{developer.title()}, we are excited to have you on board!\n")

Output:
Hello, Alice! Welcome to the team.
Alice, we are excited to have you on board!

Hello, Bob! Welcome to the team.
Bob, we are excited to have you on board!

Hello, Charlie! Welcome to the team.
Charlie, we are excited to have you on board!

Hello, David! Welcome to the team.
David, we are excited to have you on board!

4. DOING SOMETHING AFTER A FOR LOOP
-----------------------------------------------------------------------------------------------------------------------------------------------------
* Post-Loop Operations: Any lines of code after the for loop that are not indented execute only once after the entire loop has finished running.

Code Example:
>>> developers = ['alice', 'bob', 'charlie', 'david']
>>> for developer in developers:
>>>     print(f"Hello, {developer.title()}! Welcome to the team.")
>>>     print(f"{developer.title()}, we are excited to have you on board!\n")
    
>>> print("All developers have been welcomed!")

Output:
Hello, Alice! Welcome to the team.
Alice, we are excited to have you on board!

Hello, Bob! Welcome to the team.
Bob, we are excited to have you on board!

Hello, Charlie! Welcome to the team.
Charlie, we are excited to have you on board!

Hello, David! Welcome to the team.
David, we are excited to have you on board!

All developers have been welcomed!

5. AVOIDING INDENTATION ERRORS
-----------------------------------------------------------------------------------------------------------------------------------------------------
* 5.1 Forgetting to Indent: Always indent the line after the for statement. Forgetting raises an IndentationError.

Incorrect Code Example:
>>> developers = ['alice', 'bob', 'charlie', 'david']
>>> for developer in developers:
>>> print(developer)

* Error Output:
  File "c:\Users\Sourov\OneDrive\Desktop\VS Code\for_loop_developers.py", line 3
    print(developer)
    ^^^^^
IndentationError: expected an indented block after 'for' statement on line 2

* 5.2 Forgetting to Indent Additional Lines: Creates a logical error where the unindented line executes only once after the loop finishes.

Incorrect Code Example:
>>> developers = ['alice', 'bob', 'charlie', 'david']
>>> for developer in developers:
>>>     print(f"Hello, {developer.title()}! Welcome to the team.")
>>> print(f"{developer.title()}, we are excited to have you on board!\n")

* Logical Error Output:
Hello, Alice! Welcome to the team.
Hello, Bob! Welcome to the team.
Hello, Charlie! Welcome to the team.
Hello, David! Welcome to the team.
David, we are excited to have you on board!


* 5.3 Indenting Unnecessarily: Indenting code that does not belong to an indented block raises an unexpected indent error.

Incorrect Code Example:
>>> message = "I love scritping in Python!"
>>>     print(message)

* Error Output:
  File "c:\Users\Sourov\OneDrive\Desktop\VS Code\for_loop.py", line 2
    print(message)
IndentationError: unexpected indent


* 5.4 Indenting Unnecessarily After Loop: Causes summary statements intended for post-loop execution to repeat unnecessarily inside the loop.

Incorrect Code Example:
>>> developers = ['alice', 'bob', 'charlie', 'david']
>>> for developer in developers:
>>>     print(f"Hello, {developer.title()}! Welcome to the team.")
>>>     print(f"{developer.title()}, we are excited to have you on board!\n")
>>>     print("All developers have been welcome to the team!")

* Logical Error Output:
Hello, Alice! Welcome to the team.
Alice, we are excited to have you on board!

All developers have been welcome to the team!
Hello, Bob! Welcome to the team.
Bob, we are excited to have you on board!

All developers have been welcome to the team!
Hello, Charlie! Welcome to the team.
Charlie, we are excited to have you on board!

All developers have been welcome to the team!
Hello, David! Welcome to the team.
David, we are excited to have you on board!

All developers have been welcome to the team!


* 5.5 Forgetting the Colon: Omitting the colon (:) at the end of a for statement raises a SyntaxError.

Incorrect Code Example:
>>> developers = ['alice', 'bob', 'charlie', 'david']
>>> for developer in developers
>>>    print(developer)

* Error Output:

                               ^
