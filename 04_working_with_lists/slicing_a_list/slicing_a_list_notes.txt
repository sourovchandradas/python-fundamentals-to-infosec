=====================================================================================================================================================
                                                            SLICING A LIST
=====================================================================================================================================================

OVERVIEW
-----------------------------------------------------------------------------------------------------------------------------------------------------
In Python, working with a specific group of items in a list is called slicing. Slices allow developers to extract, iterate through, or copy 
subsets of data efficiently without modifying the original collection.


1. SLICING A LIST
-----------------------------------------------------------------------------------------------------------------------------------------------------
* Basic Syntax: list_name[start_index:stop_index]. Python stops one item before the stop_index (off-by-one mechanism).

Code Example:
players = ['charles', 'martina', 'michael', 'florence', 'eli']
print(players[0:3])

Output:
['charles', 'martina', 'michael']

* Starting from Beginning: Omitting the first index defaults to index 0 ([:4]).
* Slicing to the End: Omitting the second index slices through the end of the list ([2:]).
* Negative Indices: Use negative values to slice relative to the end (e.g., [-3:] gets the last 3 elements).


2. LOOPING THROUGH A SLICE
-----------------------------------------------------------------------------------------------------------------------------------------------------
* Subsets in Loops: You can use a slice directly in a for loop to iterate over a subset instead of the entire list.

Code Example:
players = ['charles', 'martina', 'michael', 'florence', 'eli']
for player in players[:3]:
    print(player.title())

Output:
Charles
Martina
Michael


3. COPYING A LIST
-----------------------------------------------------------------------------------------------------------------------------------------------------
* Correct Copying Syntax: Use entire list slice ([:]) to make a true independent copy of a list.

Code Example:
my_foods = ['pizza', 'falafel', 'carrot cake']
friend_foods = My_foods[:]

my_foods.append('cannoli')
friend_foods.append('ice cream')

print(my_foods)
print(friend_foods)

Output:
['pizza', 'falafel', 'carrot cake', 'cannoli']
['pizza', 'falafel', 'carrot cake', 'ice cream']

* Reference Warning: Setting friend_foods = my_foods makes both variables point to the exact same list in memory (modifying one alters both).
