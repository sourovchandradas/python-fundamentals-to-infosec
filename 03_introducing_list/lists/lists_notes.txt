                                                              INTRODUCING LISTS & AVOIDING INDEX ERRORS
=============================================================================================================================================================

OVERVIEW
-------------------------------------------------------------------------------------------------------------------------------------------------------------
A list is a collection of items in a particular order. You can include letters, digits, or names in a list. 
The items do not have to be related in any particular way. Because a list usually contains more than one element, 
it is best practice to make the name of your list plural (e.g., letters, digits, bicycles).


1. WHAT IS A LIST?
-------------------------------------------------------------------------------------------------------------------------------------------------------------
* Definition: Square brackets ([]) indicate a list, and individual elements are separated by commas.

Code Example:
>>> countries = ['india', 'sweden', 'canada', 'morocco']
>>> print(countries)
['india', 'sweden', 'canada', 'morocco']

* Note: Printing a list directly returns its raw representation, including square brackets and quotes.


2. ACCESSING ELEMENTS IN A LIST
-------------------------------------------------------------------------------------------------------------------------------------------------------------
* Definition: Lists are ordered collections. You access any element by providing its position or index in square brackets.
* String Methods: You can apply string methods (like title(), upper(), lower()) directly to list elements.

Code Example:
>>> countries = ['india', 'sweden', 'canada', 'morocco']
>>> print(countries[0])
india
>>> print(countries[0].title())
India


3. INDEX POSITIONS START AT 0, NOT 1
-------------------------------------------------------------------------------------------------------------------------------------------------------------
* Zero-Based Indexing: Python starts counting list items at index 0, not 1.
  - First item: Index 0
  - Second item: Index 1
  - Fourth item: Index 3 (subtract 1 from position)
* Negative Indexing: Index -1 always returns the last item in a list.
  - Last item: Index -1
  - Second from end: Index -2
  - Third from end: Index -3

Code Example:
>>> countries = ['india', 'sweden', 'canada', 'morocco']
>>> print(countries[1])
sweden
>>> print(countries[3])
morocco
>>> print(countries[-1])
morocco


4. USING INDIVIDUAL VALUES FROM A LIST
-------------------------------------------------------------------------------------------------------------------------------------------------------------
* Usage: Individual list items can be used just like any other variable (e.g., in string concatenation or f-strings).

Code Example:
>>> countries = ['india', 'sweden', 'canada', 'morocco']

>>> message = f"I want to visit {countries[0].title()}."
>>> print(message)
I want to visit India.


5. AVOIDING INDEX ERRORS WHEN WORKING WITH LISTS
-------------------------------------------------------------------------------------------------------------------------------------------------------------
* Common Cause: Requesting an index that does not exist results in an IndexError (off-by-one counting error).
  Example: Asking for index 3 in a list with 3 elements (indices 0, 1, 2).

Code Example (IndexError):
>>> countries = ['india', 'sweden', 'canada', 'morocco']
>>> print(countries[4])
Traceback (most recent call last):
  File "countries.py", line 2, in <module>
    print(countries[4])
IndexError: list index out of range

* Special Edge Case: Using index -1 on an empty list [] also results in an IndexError because there are no items.
* Troubleshooting Tip: If an index error occurs, try printing the list or printing len(list) to see its actual size.
