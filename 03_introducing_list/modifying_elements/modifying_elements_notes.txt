=====================================================================================================================================================
                                                      MODIFYING, ADDING, AND REMOVING ELEMENTS
=====================================================================================================================================================

OVERVIEW
---------------------------------------------------------------------------------------------------------------------
Python lists are dynamic data structures. Elements can be added, modified, or removed at runtime as program state 
changes. Python provides various built-in methods and statements to manage list items efficiently. Let's look at 
how Python handles updating list contents dynamically.


1. MODIFYING ELEMENTS IN A LIST
---------------------------------------------------------------------------------------------------------------------
* Concept: To change an element's value, reference its index position and assign a new value.

Code Example:
>>> oceans = ['pacific', 'atlantic', 'arctic']
>>> oceans[0] = 'indian'
>>> print(oceans)
['indian', 'atlantic', 'arctic']


2. ADDING ELEMENTS TO A LIST
---------------------------------------------------------------------------------------------------------------------
* Appending Elements: The append() method adds an element to the end of a list without altering existing items. 
  This is useful for dynamically building lists from scratch.

Code Example:
>>> oceans = ['pacific', 'atlantic', 'arctic']
>>> oceans.append('indian')
>>> print(oceans)
['pacific', 'atlantic', 'arctic', 'indian']

* Building a list dynamically
>>> oceans = []
>>> oceans.append('pacific')
>>> oceans.append('atlantic')
>>> oceans.append('arctic')
>>> print(oceans)
['pacific', 'atlantic', 'arctic']


* Inserting Elements: The insert() method inserts an element at a specified index position, shifting subsequent 
  elements one position to the right.

Code Example:
>>> oceans = ['pacific', 'atlantic', 'arctic']
>>> oceans.insert(0,'indian')
>>> print(oceans)
['indian', 'pacific', 'atlantic', 'arctic']


3. REMOVING ELEMENTS FROM A LIST
---------------------------------------------------------------------------------------------------------------------
* Removing by Position (del): Permanently deletes an item at a specified index when the removed value is no 
  longer needed.

Code Example:
>>> oceans = ['pacific', 'atlantic', 'arctic']
>>> del oceans[1]
>>> print(oceans)
['pacific', 'arctic']

* Removing and Retaining (pop()): The pop() method removes an item from a list while allowing its value to be 
  stored in a variable for further use.

Code Example:
>>> oceans = ['pacific', 'atlantic', 'arctic']

* Pop list item
>>> popped_ocean = oceans.pop()
>>> print(oceans)
>>> print(popped_ocean)
['pacific', 'atlantic']
arctic

* Pop by index
>>> first_ocean = oceans.pop(0)
>>> print(f"The largest ocean in the world is the {first_ocean.title()} Ocean.")
The largest ocean in the world is the Pacific Ocean.

* Decision Rule: Use del when an item should be permanently deleted without reuse. Use pop() when the 
  removed item's value is needed after removal.

* Removing by Value (remove()): Deletes an item by value when its exact position is unknown.

Code Example:
>>> oceans = ['pacific', 'atlantic', 'arctic','indian']
>>> too_deep = 'pacific'
>>> oceans.remove(too_deep)
>>> print(oceans)
>>> print(f"The deepest part of the world's oceans is the Challenger Deep in the Mariana Trench, located in the {too_deep.title()} Ocean.")
['atlantic', 'arctic', 'indian']
The deepest part of the world's oceans is the Challenger Deep in the Mariana Trench,located in the Pacific Ocean.

* Note: The remove() method deletes only the first occurrence of the specified value. A loop is required if 
  duplicate values need to be removed.
